Эксперимент

Локальная база макета

Загружаем структуру одного макета через Figma API, оставляем только нужное для поиска — тип, название, видимость, вложенность, связь с компонентом, текст, размеры и координаты — и сохраняем в локальную базу. Смотрим, сколько это занимает времени и места.

Ссылка на страницу или секцию — загрузится только она. Ссылка на файл — страницы по правилам из настроек.

Ищем без запросов к Figma — только по загруженной базе: инстансы компонента (по точному названию), фреймы, секции, группы, мастер-компоненты и другие слои по названию, тексты по содержимому. Регистр не важен.
