# Архив: прежние варианты поиска

Здесь лежит функционал, убранный из основного интерфейса 28.09.2026. Он не подключён к серверу
и не запускается; файлы сохранены как были, чтобы при необходимости их можно было вернуть.

| Что | Файлы |
|---|---|
| Вкладка «1 · через API» — поиск инстансов компонента через Figma REST API с кэшем на 5 минут, выбор между одноимёнными компонентами, выделение через плагин | `app/static/index.html`, `app/search.py`, эндпоинты `/api/search` и `/api/figma/*` в `app/main.py` |
| Вкладка «2 · без скачивания» — поиск внутри открытого файла через плагин Figma | `app/static/plugin.html`, `app/plugin_bridge.py` |
| Плагин «Search Agent — выделение» (для варианта 1) | `figma-plugin/` |
| Плагин «Search Agent — поиск без скачивания» (для варианта 2) | `figma-plugin-search/` |
| Прежняя вкладка «Эксперимент» (загрузка по ссылке, замеры, история загрузок) | `app/static/experiment.html` |
| Тесты этих функций | `tests/test_search.py` |

`app/main.py`, `app/__main__.py` и `app/figma_client.py` — снимки на момент архивации, целиком
(в них и прежний порт 8002 для плагинов).

## Как вернуть

1. Скопировать нужные файлы обратно в `app/` и `app/static/` (плагины — в корень проекта).
2. Перенести из `archive/app/main.py` в `app/main.py` нужные эндпоинты и подключение роутера
   (`from .plugin_bridge import router as plugin_router` и `app.include_router(plugin_router)`).
3. Для плагинов вернуть второй порт 8002 из `archive/app/__main__.py`.
