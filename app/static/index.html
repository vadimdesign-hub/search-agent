Поиск по макетам

Найдите компонент, фрейм, картинку, любой слой или текст сразу во всех загруженных макетах. Поиск идёт по локальной базе — мгновенно и без запросов к Figma.

Инстансы компонента — по точному названию компонента; фреймы, секции, группы, картинки и другие слои — по названию; тексты — по содержимому. Регистр не важен. Ширина, высота и цвет (заливка, цвет текста или обводка) — точные: с названием уточняют поиск, без названия находят все такие объекты.
